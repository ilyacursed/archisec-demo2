# АрхиСек: локализация и фирменный стиль

## Граница изменений

Локализация — только представление существующего MVP. Analyzer, валидация профиля, repository, JSON seed data и mappings остаются прежними. В API не переводятся ключи, значения категорий, тексты ошибок и metadata. HTML использует русские подписи и названия; поля формы сохраняют исходные машинные значения, порядок, дубли и неизвестные строки.

`services/terminology.py` содержит единые словари отображения. Тонкие filters в `core/templatetags/terminology.py` применяют их в шаблонах. Известные термины переводятся точным lookup без substring replacement, trim или case folding. Неизвестный пользовательский текст остаётся дословным и экранируется Django. Перевод имени/описания сущности применяется только при совпадении кода, поля и ожидаемого исходного текста: пользовательские и синтетические сущности не подменяются.

HTML-ошибки валидации имеют фиксированный русский текст без отражения входных данных. API errors и framework-generated debug/CSRF страницы не переопределяются ради оформления.

## Логотип

Исходник: `static/img/archisec-logo.png`, PNG 1254 × 1254. Это предоставленный пользователем логотип, а не сгенерированная замена. Файл сохраняется без изменения. На HTML-страницах логотип используется только в header; повторное изображение в hero удалено. Header и favicon используют Django static files. README ссылается на тот же asset.

Логотип отображается целиком: без обрезки, перекраски, CSS filters и растяжения. CSS задаёт пропорциональные размеры. В исходнике есть широкие светлые поля; они сохраняются как часть изображения. При уменьшении до favicon знак менее различим — символ не вырезается и не перерисовывается без отдельного согласования.

## Палитра

- `--archisec-green: #6AAF9C` — зелёно-бирюзовый акцент.
- `--archisec-blue: #4182AE` — синий акцент.
- Контрастные производные синего предназначены для ссылок, focus и кнопок с белым текстом.
- Основной фон светлый; текст и границы нейтральные. Предупреждение о демонстрационных данных использует спокойный семантический оттенок.

## Компактный header и темы

Header использует полную ширину с небольшими боковыми отступами: слева исходный логотип и «Демонстрация», справа навигация, «Войти» и переключатель темы. Дополнительный текст `brand-name` удалён. На узких экранах элементы переносятся без горизонтального overflow; интерактивные цели сохраняют комфортный размер.

«Войти» — инертная демонстрационная кнопка, а не authentication flow. Она не отправляет форму, не меняет URL и не создаёт users/sessions. Подсказка сообщает, что вход недоступен в демонстрационной версии.

Клиентский `static/js/theme.js` переключает светлую/тёмную тему через `data-theme` у корневого HTML-элемента. В светлой теме показывается луна (действие «Включить тёмную тему»), в тёмной — солнце (действие «Включить светлую тему»). Используется нативная keyboard-accessible кнопка с доступным именем, состоянием и видимым focus. Без JavaScript переключатель недоступен; основные страницы и формы продолжают работать.

Единственный сохраняемый выбор — `archisec-theme` в `localStorage`, значение `light` или `dark`. Отсутствующий/невалидный выбор означает светлую тему, независимо от системных предпочтений. Ошибки чтения/записи storage обрабатываются: переключение остаётся доступным в текущем документе. Профиль, результаты, персональные данные и серверные preferences не сохраняются.

Тёмная тема не инвертирует страницу или логотип: переопределяются производные tokens фона, поверхностей, header, input, notice, текста, границ, ссылок и кнопок. Точные брендовые `--archisec-green` и `--archisec-blue` остаются прежними. Цвет текста ссылки и фон primary button разделены для контраста в обоих режимах. Светлые поля исходного PNG сохраняются и в тёмной теме.

Точные брендовые hex-коды задаются только в tokens, дальнейшие CSS rules используют переменные. Брендовый зелёный не применяется как мелкий текст на белом фоне. Проверка контраста ориентируется на WCAG AA: 4.5:1 для обычного текста, 3:1 для значимых границ/focus.

## Терминология

Основные понятия: «Профиль системы», «Угроза», «Мера защиты», «Средство защиты информации (СЗИ)», «Анализ», «Результат анализа», «Статистика». Категории показываются русскими подписями: «Конфиденциальность», «Целостность», «Доступность», «Доступ из интернета», «Искусственный интеллект». Названия демонстрационных сущностей локализуются без изменения их кодов или данных API.

Демонстрационный статус изложен по-русски: данные не подтверждены, не являются нормативной рекомендацией или официальными сведениями ФСТЭК. Наличие цепочек не подтверждает эффективность защиты или сертификацию.

## Проверки

Существующие проверки поведения и API сохраняются; обновляются только ожидания переводимого HTML-текста. Дополнительно проверяются словари, fallback и escaping, сохранность API/формы, logo/favicon/static, tokens, контраст и отсутствие горизонтального overflow на узкой, средней и desktop ширине. Фактические результаты фиксируются отдельным QA и read-only Reviewer, а не заявляются этим документом.
