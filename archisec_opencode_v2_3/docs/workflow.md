# Workflow

1. Orchestrator inspects repository.
2. Architect confirms boundaries.
3. Data agent validates demo catalog and mappings.
4. Backend implements repository/services/API.
5. Frontend implements HTML views/templates.
6. QA runs tests and smoke checks.
7. Reviewer performs read-only review.
8. Orchestrator resolves findings and reports status.

Do not let two agents edit the same files concurrently.
